# Typoglycemia Demo

文字の並び順をシャッフルしても人間が読めてしまう現象「タイポグリセミア」を題材に、AIモデルがどれだけ崩れた文章を読解できるかを試せるWebデモアプリ。

研究（自然言語処理・タイポグリセミア）で得た関心を、実際に動くシステムとして形にすることを目的とする。研究内容そのものではなく、一般公開できる範囲のデモとして構築する。

## 機能

1. 入力した文章の各単語の内部文字をランダムにシャッフルする
2. シャッフル後の文章を言語モデルに読ませ、意味の推定・訂正を行わせる
3. シャッフル前後の文章と、モデルの出力を並べて表示する
4. シャッフル強度（どれくらい文字を入れ替えるか）を調整できる

## 構成

```
backend/    # FastAPI, シャッフル処理・モデル推論API
frontend/   # 入力フォーム・結果表示のシンプルなUI（React）
docker-compose.yml
```

## 技術スタック（予定）

- Backend: Python / FastAPI
- モデル: 既存の軽量言語モデル（Hugging Face等）をAPI経由 or ローカル推論で利用
- Frontend: React（Vite）
- デプロイ: Docker化した上でRender / Fly.io等の無料枠を想定
